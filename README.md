# Aires Neto Portfolio

Personal portfolio for selected engineering work, current projects and professional experience.

The site is intentionally kept as a lightweight static build so the engineering work stays the main focus.

## Current focus

The portfolio is being rebuilt around a smaller number of deeper projects that show architecture, implementation, testing, observability and delivery rather than a large collection of small demos.

The current flagship project is **Switchyard**, a distributed commerce and fulfilment platform being developed in stages.

Supporting projects currently include:

- OpsFlow
- EventFlow
- .NET Observability API

## Stack

The site uses plain HTML, CSS and JavaScript and is hosted with GitHub Pages.
